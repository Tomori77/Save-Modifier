# 口袋修仙 · 存档工坊

《口袋修仙》（Pocket Cultivation）本地存档修改工具。单文件本地服务：双击运行后自动打开浏览器，可视化增删改存档中的物品、角色信息与灵根。

> 支持 **Demo**（当前开放版）与 **Playtest**，自动识别已安装的游戏版本，并读取对应版本的物品与图标。

## 功能

- **多版本自动识别**：自动扫描 Steam 库与 `%APPDATA%`，列出本机已安装的 Demo / Playtest；切换版本后物品目录、图标、存档列表全部跟随该版本。
- **版本自适应**：
  - 物品目录、图标实时读取对应版本的游戏 / ModSDK 数据；
  - 境界表从游戏本体实时提取（各版本境界与层数不同，如 Demo 炼气期 10 层、Playtest 7 层）；
  - 分类、品级、元素等筛选由该版本实际数据动态生成。
- **物品编辑**：
  - 储物袋网格视图（品级描边、已放置标记、唯一法宝标记、数量角标）；
  - 物品总览目录（检索、分类筛选、一键添加）；
  - 右键改数量、左键看详情；唯一法宝自动限制为 1 件。
- **角色信息编辑**：角色名、境界、层数、灵石、金木水火土灵根。
- **安全写入**：
  - 保存前自动备份到 `backups/<日期>/<存档名>.json`，再覆盖原存档；
  - 重算并写入存档哈希；保存时同步游戏存档列表摘要（`catalog.json`），避免角色名/境界回退。
- **游戏运行检测**：检测到游戏正在运行时会提示，避免写冲突。

## 使用

### 方式一：下载 exe（推荐）

1. 前往 [Releases](https://github.com/Tomori77/Save-Modifier/releases) 下载最新的 `口袋修仙存档工坊.exe`。
2. 双击运行，浏览器会自动打开 `http://127.0.0.1:8765`。
3. 在页面顶部选择游戏版本与存档，开始编辑。

> 首次运行会扫描本机游戏安装与存档目录。若未找到，可在 exe 同目录放置 `game-assets.txt`，写入游戏安装根目录（含 `resources/public` 的那一级）。

### 方式二：从源码运行

```powershell
python src/server.py
```

依赖：Python 3.8+（仅标准库，无需第三方包）。生成《坊市定向寻物表》需额外安装 `openpyxl`。

## 目录结构

```
save-editor/
├─ src/
│  ├─ server.py            # 本地服务：版本识别、存档读写、物品目录
│  └─ gen_search_xlsx.py   # 生成《坊市定向寻物表.xlsx》（可选）
├─ web/
│  └─ index.html           # 前端界面
├─ assets/                 # 打包图标（icon.ico / icon.png）
├─ backups/                # 存档备份（运行时生成）
├─ output/                 # 寻物表产物（运行时生成）
└─ 口袋修仙存档工坊.spec    # PyInstaller 打包配置
```

## 游戏版本识别

| 版本 | Steam AppID | 存档目录（%APPDATA%） |
|---|---|---|
| Demo | 4777710 | `Pocket Cultivation Demo/saves` |
| Playtest | 5106860 | `Pocket Cultivation Playtest/saves` |
| 正式版 | 4707190 | `Pocket Cultivation/saves` |

游戏安装目录通过 Steam `appmanifest_<appId>.acf` 的 `installdir` 定位，支持自定义安装路径与多库盘。

## 备份与还原

- 每次保存前，选定存档会**先复制**到 `backups/<日期>/`，再覆盖原文件；同日多次保存同一存档会追加时间后缀避免覆盖。
- 还原：关闭游戏，用备份目录中的文件覆盖 `%APPDATA%` 下对应存档，重启游戏即可。

## 打包

```powershell
pyinstaller 口袋修仙存档工坊.spec
```

产物在 `dist/`。spec 已内嵌版本信息与图标。
